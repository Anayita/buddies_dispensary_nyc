# Buddies Dispensary NYC 🌿

Landing page oficial para **Buddies Dispensary NYC**, dispensaria legal de cannabis en Nueva York (Lower East Side, Mott Haven y Yankee Stadium).

> *"You get New York's finest. We get second chances."*

---

## 🚀 Características

- **Diseño Responsive Moderno**: Mobile-first, optimizado para conversión, desktop y tablets.
- **HTML5 + CSS3 + Vanilla JS**: Sin frameworks pesados ni dependencias externas de pago.
- **Verificación de Edad 21+**: Modal bloqueante conforme a las leyes del Estado de Nueva York (NYS OCM).
- **Selector de Tiendas Activo**: Lower East Side (LES), Mott Haven y Yankee Stadium.
- **Catálogo y Favoritos**: 8 categorías de producto, más vendidos y carrito con notificaciones toast.
- **Cumplimiento Legal**: Licencias NYS OCM, advertencias de consumo responsable y línea de ayuda NY HOPEline (1-877-8-HOPENY).

---

## 🛠️ Ejecución Local

Puedes probar el sitio abriendo `index.html` en tu navegador o levantando el servidor Node.js incluido:

```bash
node server.js
```

Y abrir `http://localhost:3000`.
